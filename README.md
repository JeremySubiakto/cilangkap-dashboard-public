# Dashboard Akuisisi — prototipe publik (ODP 358)

Prototipe internal program ODP 358 untuk KCP Jakarta Cilangkap. **Bukan situs atau layanan resmi Bank Mandiri.**

- Hanya berisi kode aplikasi dan data publik (OpenStreetMap, Overture Maps, Dapodik/Sekolah Kita, data publik properti). Tidak ada data nasabah atau data internal bank.
- Brankas data (`data/vault.js`) salinan ini dibuat terpisah dan kosong.
- Atribusi data: © kontributor OpenStreetMap (ODbL), Overture Maps Foundation, Kemendikdasmen (Dapodik).
