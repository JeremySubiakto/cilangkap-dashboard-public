# Dashboard Akuisisi — prototipe publik (ODP 358)

Prototipe internal program ODP 358 untuk KCP Jakarta Cilangkap. **Bukan situs atau layanan resmi Bank Mandiri.**

- Hanya berisi kode aplikasi dan data publik (OpenStreetMap, Overture Maps, Dapodik/Sekolah Kita, PDDikti, registri fasilitas kesehatan Kemenkes, statistik BPS, data publik properti). Tidak ada data nasabah atau data internal bank. Omzet usaha di peta adalah perkiraan dari data publik, bukan data pajak atau data rekening.
- Brankas data (`data/vault.js`) salinan ini dibuat terpisah dan kosong.
- Atribusi data: © kontributor OpenStreetMap (ODbL), Overture Maps Foundation, Kemendikdasmen (Dapodik), Kemdiktisaintek (PDDikti), Kementerian Kesehatan, Badan Pusat Statistik. Rincian sumber dan lisensi ada di bagian `meta` setiap berkas `data/*.js`.
